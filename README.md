# Magazine Layout

A responsive magazine-style webpage built as part of my **freeCodeCamp Responsive Web Design** practice.

## About the Project

This project focuses on creating a magazine layout using **HTML and CSS Grid**. I practiced structuring content into different sections, working with images, typography, quotes, and responsive layouts.

## What I Practiced

* HTML semantic elements
* CSS Grid
* Responsive design with media queries
* CSS typography and Google Fonts
* Working with images
* Creating multi-column layouts
* Basic responsive breakpoints
* Font Awesome icons

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Google Fonts
* Font Awesome

## Project Features

* Magazine-style page layout
* Responsive design for different screen sizes
* Hero section with title and subtitle
* Author and publication information
* Social media icons
* Multi-column text layout
* Images and quotes
* Responsive image and content sections

## What I Learned

Through this project, I practiced using **CSS Grid** to create complex layouts and learned how **media queries** can make a webpage adapt to different screen sizes.
